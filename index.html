Общие сведения

Перевозчик представляет собой классическую задачу о лодке, человеке, козе, капусте и волке. Ее принцип прост: нужно перевезти капусту, козу и волка с одного на другой берег.

Применение

  • С 5-го класса

    Программу можно применять как задачу на логику. Для детей 11-12 лет не слишком сложное, в нем нельзя запутаться.

  • С 7-го класса

    Программу можно использовать для изучения простейших алгоритмов на курсах информатики с 7-го класса.

  • В старших классах

    Открытый исходный код программы также позволяет изучать программирование на языке C#, базовые и общие для всех остальных языков конструкции.

Системные требования

  • Версия ОС: Windows 7 и выше

  • Необходимые библиотеки:

      • Microsoft Visual C++ 2015 - 2022 (ARM64, x86, x64)

      .NET Desktop Runtime 8.0 (ARM64, x86, x64)

Скачивание и установка

  • Скачать программу можно при помощи кнопок вверху страницы.

  • Установка состоит из следующих этапов:

    1. Скачать .zip или .tar.gz архив и распаковать в любую папку

    2. Запустить Carrier.exe

    3. Установить необходимые библиотеки, если программа запускается с ошибкой
